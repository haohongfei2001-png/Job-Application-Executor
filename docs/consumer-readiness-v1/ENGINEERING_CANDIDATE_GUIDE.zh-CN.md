## 取得正确的候选包

1. 只使用交付说明中**对应完整 Git 提交 SHA** 的成功 CI 运行，核对该运行的实际 checkout/测试提交与交付回执。不要因为某个旧运行有附件就把它当作当前版本；普通构建附件可能早于全套测试完成，须等待对应运行成功。
2. 根据该运行的触发方式下载附件，两条现有路径都受支持：
   - 普通 `main` push 或非 Draft PR 运行：`jae-unsigned-macos-<运行号>-<尝试号>`。名称不包含提交号，必须用上述运行与回执绑定完整 SHA。
   - 明确添加匹配当前完整 SHA 的 `eng-<完整提交SHA>` 标签所触发的工程收口运行：`jae-engineering-NOT_CERTIFIED-<完整提交SHA>-<运行号>-<尝试号>`，详见[工程收口规则](ENGINEERING_CLOSURE.md)。普通 Draft PR 不默认生成候选包；普通 push 不生成这个标签路径的附件。
   - 两条路径解压 GitHub 外层 ZIP 后，完整文件夹都应同时包含 `AIApplicationManager-unsigned.tar.gz` 和 `distribution-manifest.json`。
3. 清单应标明 `signing: unsigned`、`certification: NOT_CERTIFIED`、`final_click_actor: user`、`task_state: excluded`。可用 macOS 的 `shasum -a 256 AIApplicationManager-unsigned.tar.gz` 核对 `archive_sha256`。GitHub 附件摘要对应外层 ZIP，不是这个内层归档摘要；清单里的 `source_sha256` 是源码载荷摘要，不是 40 位 Git 提交号。
4. 附件仅保留 7 天；过期不是安装成功或失败的证据。没有对应成功运行及完整清单时，请勿安装。已有完整成功运行及正确附件时，不为补写交付回执而重新构建或重跑。

## 先准备资料

1. 打开应用，进入 **资料设置 → 编辑基本资料与简历**。本地编辑和查看清单不调用模型，也不把这些资料发送到招聘网站。
2. 核对姓名、电话、邮箱等可编辑项。**已记录** 仅说明本机有值；**缺少记录** 需要本人补充。旧版格式、特殊字段格式及已有结构化教育记录可能只读，原数据仍保留。
3. 需要时选择 PDF、DOCX 或 DOC 简历。文件及请求内容合计最多 20 MiB；只保存原始文件，不解析、预览、执行或上传。替换文件不会自动更新旧简历的解析事实，请同时核对资料是否一致。
4. 点击 **保存给以后新任务**，等待“已保存在本机并重新读取确认”。

**仅用于以后新任务，已有任务仍使用原资料。** 清空某项是明确清除该值。没有修改的项目、未知元数据和已有证件资料会保留；证件号码不在此界面展示或编辑。

关闭、Escape、刷新或会话失效会清除尚未保存的输入和文件选择；不会在浏览器存储里偷偷保存。如果提示“保存尚未确认”，不要重复点保存，先用 **重新读取并核对** 检查实际记录。损坏的托管资料/新简历会阻止新任务绑定，重新启动也不会跳过检查；需要恢复可信文件或通过原有 JSON 导入选定完整资料后再明确核对。已有任务不会因此被重绑或自动重试。

## 当前原生准备流程

原生准备入口已接入应用，但还不是完整投递或本人设备验收。它仅支持通过当次安全检查的 Apple Silicon Mac、已安装的 Google Chrome 和候选版固定的驱动环境；不满足条件时明确拒绝，不会改用你的既有浏览器标签页。

原生准备在独立的私密子进程中运行。关闭、取消或主应用退出会撤销子进程；无法证明浏览器与驱动已结束时，不会另开窗口或自动重试。常规填写和简历上传的逐次确认要求不变。

1. 在本地拟填写内容中勾选并核对常规资料，可先只读核对官网，也可打开独立的原生准备窗口。先前检查会先取消，确认原浏览器已关闭后才启动新窗口；无法证明关闭时不另开、不自动重试。
2. 新窗口通过当次网络隔离自检和官网结构核对后，应用再次显示本次填写的接收方、范围和确认选项。只有你单独确认，才执行该计划一次。填写结果只是当前文档观察，不能当作网站草稿或投递成功。
3. 需要上传简历时，应用另行核对原文件类型、大小、固定接收方和本机版本，并要求单独确认。返回结果仍会明确说明附件留存未经验证；不自动重复上传。
4. 在本次填写及需要的原始简历上传完成后，可点击 **显示官网验证码，进入人工收尾**。只在原有受控启云方窗口显示一次官网验证码图片，不读取、识别或代填验证码。请本人在该原生窗口核对并补完证件、验证码、协议等受保护内容；不要把这些值交给聊天、剪贴板或应用日志。图片无法确认时会拒绝，不自动刷新或重试；收尾开始后再刷新验证码会使本次核对失效。
5. 本人点击官网提交后，请求先被暂停。仅匹配同一请求、窗口、页面与当前资料的原生确认框，在你亲自确认后发送一次。应用不代点确认，不向其他网站发送，也不会在超时或结果不明时重传。
6. 返回后原生页面最多继续显示五分钟（或原会话更早到期），用于本人查看官网结果。所有后续网络和再次填写/上传/提交均被拒绝。请求返回不代表申请成功，仍需本人核验网站实际结果。关闭或隐藏会清除私密显示并结束拥有的会话。

工程测试只使用合成资料和独立本地接收端。真实申请资料、官网验证码/会话、本人原生确认和最终申请尚未实机验收；不能为了取得测试证据而代替本人处理证件、验证码、协议或最后确认。
