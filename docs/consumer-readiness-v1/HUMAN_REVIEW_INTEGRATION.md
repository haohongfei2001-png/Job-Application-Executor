# Private-child human-review integration

The existing native preparation controller and its private child now have one
explicit review transition. The private local UI can ask to begin review and
observe fixed status values. It cannot confirm, accept a dialog, supply protected
fields, or command a final request. The explicitly approved production capability is limited to the fixed Qiyunfang
contract in its original admitted native owner. It displays one exact official
CAPTCHA image before arming the final classifier, then permits only the existing
opaque final POST after paired native user confirmation. No arbitrary site,
parent-confirmation method or runtime enable flag exists. Actual owner/site
acceptance remains separate from synthetic engineering evidence.

## One owner and one transition

For isolated synthetic admission, the classifier is installed after the exact
native browser self-check and before the public form page exists. Beginning
review arms the existing classifier without sealing the user's still-editable
form. The pinned XHR wrapper seals the change epoch only when the final request
is made. Route callbacks retain the exact native Request or abort; they never
read protected body values or perform nested browser RPCs.

The controller then gives the review coordinator sole ownership of its guard
loop. It cannot resume routine filling or start another upload. After capture,
the coordinator constructs the existing durable final journal and opaque bridge
for that exact process, frame, document, task/material versions and epoch.
Native opening/closed events feed the bridge. No product method accepts a dialog.
During the modal the owner pumps events and checks parent liveness/expiry, without
renderer RPCs that would deadlock behind the dialog. After the matching close,
full guards run before durable one-slot consumption and the one opaque request.

In the approved production path, a returned/unknown result leaves the native
page visible for at most five minutes or the earlier original deadline. Every
further network request and action stays denied; the final slot remains spent.
The ATTEMPTED-only final journal guard is not reused after a returned receipt.
A value-free OS/session/original-material/durable-slot guard owns this readback
phase, and explicit close/cancel or scope loss retires the original browser. CLOSED still requires
independent browser/driver absence, child acknowledgment and child exit. Returned
is unverified, UNKNOWN never refunds the slot, and cancellation never retries.
Protected values/requests do not cross the child IPC, enter status, logs or durable
journal fields. The existing local routine-value preview is unchanged.

## What the synthetic evidence establishes

Hosted Mac exercises the real private child, actual native admission, controller,
classifier, journal and bridge against an independent loopback recipient. Only
the isolated fixture drives native accept/dismiss. It compares exact request
bytes and cookie/token continuity, tests refusal/uncertainty outcomes, and checks
parent-revocation, durable single consumption, no replay, canary absence and exact
original process absence. This is engineering integration evidence, not proof of
a physical human action or a successful real application.

## Remaining real gates

- Actual physical-human native confirmation on the owner's device
- Current site resource/request and CAPTCHA/session compatibility
- A separately bounded CAPTCHA-image stage, with codes entered by the person
- Actual attachment retention and final application readback
- Existing owner installation/signing and release-certification requirements

The image broker permits only GET `https://www.qiyunfang.com/validateCode.jsp?`
followed by 1–3 decimal digits and `&vCodeId=15676`, bound to the one primed native
image URL/frame and original session. It refuses redirects, non-raster MIME,
invalid signatures and bodies larger than256KiB; buffered response validation is
not a streaming-memory guarantee. It never exports pixels or reads/solves an
answer. Its deny route remains installed after one attempt. The only final
endpoint remains `https://www.qiyunfang.com/ajax/siteForm_h.jsp` with the existing
form6/role/command classifier and durable single-use native-confirmation gate.
Engineering tests use synthetic images/receivers only. No live challenge, real
applicant value or employer submission was used for these tests. Physical owner
inputs/terms/final confirmation and actual site outcome cannot be replaced with
synthetic fixtures or CI counts.
