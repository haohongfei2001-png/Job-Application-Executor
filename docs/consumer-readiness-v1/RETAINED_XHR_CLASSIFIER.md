# Retained-XHR purpose classifier research

Status: **unregistered, no forwarding method and no authorization method**.
No production session, controller, runner, HTTP endpoint or UI imports this
component. It does not accept a native dialog or enable a final request.

The version-pinned public Qiyunfang source `site.min.js?v=202506121459`, with
SHA-256 `d9e0a901236460425c9cef8a16bc06614b9336347f0384c420d840162b630da3`,
constructs a final URL-encoded POST containing a command, form ID, encoded
`submitContentList`, CAPTCHA identifier/value, temporary-file references,
submit-origin metadata and phone-code metadata. This prototype recognizes that
finite purpose shape and the fixed primary-role field. It does not certify the
correctness, ownership or acceptability of the other applicant data or file
references.

The classifier and epoch observer are composed in one ordered pre-document
initializer. Captured native XHR methods accept only async, non-credentialed
opening and a primitive string body. The renderer validates duplicate-free
parameter/field identities, field types, command/form/CAPTCHA-scope identifiers
and the public primary-role value. The percent-decoded list stays local to the
renderer; the finite JSON lexer skips protected string tokens and decodes only
metadata keys and the primary-role string. The original immutable input string
is passed once, unchanged, to the captured native send method. No protected
payload hash, extra header, copied body or body-bearing receipt is produced.

A native route owner must keep the independent deny-only transport closed and
park the exact Request. Outside route callbacks, the classifier requires the
sole observed native Request object, main frame, exact URL/method, XHR resource
type, nonredirected origin and selected content type. Identity is checked with
`is`; a caller-supplied metadata dictionary or equal-looking object cannot
substitute. Only fixed command/form/role metadata and a change epoch are returned.

Later XHRs, alternative send paths, changed epochs, failed requests and native
lifecycle loss permanently revoke the observation. Dedicated/shared worker
constructors and their prototype aliases are unavailable because their native
XHRs would bypass main-realm wrappers. Post-invalidation request retention is
bounded. Recording/debug environments are refused before installation.

## Evidence boundaries

The synthetic tests use the actual browser's paused Request and an independent
loopback receiver for exact byte, cookie and token continuity. Test-only local
HTTP dispatch is not physical-human proof. No classifier method can dispatch
that request. The separate public diagnostic installs this component only for
an unarmed, empty, read-only bootstrap; it never constructs a final request.

The caller still needs fresh exclusive ownership, source/document/process
binding, a sealed network boundary, durable one-final-slot consumption, matched
native human-confirmation provenance, cancellation ownership and private child
log/capture protection. Prior privileged scripts, protocol-injected isolated
worlds and arbitrary compromised browser execution are outside this theorem.
This purpose classifier is not a full private-field review, user intent,
resume-upload approval, CAPTCHA solution, successful application or release
certification. Runtime integration remains disabled until those distinct gates
are satisfied.
